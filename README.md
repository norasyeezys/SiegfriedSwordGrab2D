# SiegfriedSwordGrab2D
MATLAB simulation of Siegfried sword grabs (2D version)

Greedy search algorithm for Siegfried to learn a simple task... grab his sword. Part of the intent-to-action pipeline i am working on. MATLAB code confirmed working on R2015a and R2025a. Main files are `siegfried_gets_his_sword.m` and `siegfried_chases_the_sword.m`

Written by Claude Code with some of my own modifications.
